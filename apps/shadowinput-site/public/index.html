输入法：安装主程序后，在“输入法设置”安装组件，再从系统菜单切换到 shadowinput。4M 拼音排序模型随包提供，开启 AI 即可使用；Qwen 续写模型在应用内另行下载。启用短语联想后，空格上屏，稍停，按 Tab 采纳短语。

Chrome 插件：先解压 ZIP，打开 chrome://extensions，开启“开发者模式”，选择“加载已解压的扩展程序”，再选择解压后的 shadowinput 文件夹。点击插件，使用 ChatGPT 继续。无需桌面端或 API Key；这不是商店一键安装版。

这是开发预览版，哪些已经验证？+

输入法：4M 模型已在 Mac 和 Windows 完成真实推理测试，Mac 原生候选到上屏测试通过。Mac 已确认系统发现和切换，本地模型短语接口已通过真实推理冒烟测试；完整键盘输入与 Tab 采纳仍待人工验收。Windows 候选窗口、点击和请求取消已在 Windows 测试环境验证；完整安装、切换和编辑器打字流程仍待实机验收。“部门”等短词的续写缺失与 Windows 微信兼容性尚未解决，4M 排序不保证每次改变候选。Mac 尚未公证，Windows 尚未签名。已有旧版时，请退出主程序、切换到其他输入法，再更新主程序和输入法组件；若组件仍在运行，按应用提示保存工作后注销并重新登录。

插件：代码与模拟页面测试通过；用户已确认 Chrome 实装、独立登录及授权模型列表。实际翻译请求曾返回账户用量限制；完整 ChatGPT 翻译、浏览器重启后的会话恢复及真实网页兼容性仍待验收。PDF、电子书、视频字幕和图片翻译尚未实现。

插件仅在操作翻译后发送文字；如果单独开启某网站的自动翻译，也会自动发送本站正文。凭据保存在当前 Chrome 配置中，不是系统钥匙串加密。每次网页翻译最多处理 120 段。
