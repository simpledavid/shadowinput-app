# Source attribution

shadowinput is maintained by simpledavid. This repository starts an independent Git history; it is not a claim that the inherited implementation was written from scratch.

The initial source snapshot comes from the former `simpledavid/shadowinput-desktop` repository, local integration commit `75e4f84b`, including the browser extension and the phrase-label/candidate-click fixes. The inherited Arion base is [AstraFoundry/Arion at b33542061b4c70c7940676f21c2a9afb6e5f1e2a](https://github.com/AstraFoundry/Arion/tree/b33542061b4c70c7940676f21c2a9afb6e5f1e2a).

Original Arion code is developed by AstraFoundry and its contributors. Original copyright notices, the [AGPL-3.0 license](LICENSE), source headers and all bundled third-party licenses are retained. MyGo retains its [own license](third_party/mygo/LICENSE). New shadowinput modifications are distributed under AGPL-3.0-only.

The published desktop preview.6 and browser preview.3 binaries and their exact corresponding source archives are preserved in [shadowinput-app releases](https://github.com/simpledavid/shadowinput-app/releases). Their original hashes and embedded build metadata are unchanged. Each migrated tag points to a parentless snapshot of its exact original source tree; it does not import the old commit history. See the [migration record](docs/project/shadowinput-repository.md). New build metadata points to shadowinput-app.
